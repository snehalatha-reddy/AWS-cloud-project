# 🚀 Student Task Manager – AWS Cloud Project

## 📌 Project Overview

Student Task Manager is a simple web-based application hosted on AWS EC2.  
It allows users to add and delete daily tasks. The tasks are stored in browser Local Storage.

This project demonstrates cloud deployment using AWS and frontend development skills.

---

## 🌐 Deployment

Hosted on Amazon EC2 using Apache Web Server.

Access the application using:
http://your-ec2-public-ip

---

## ⚙️ How to Run Locally

1. Download the project files.
2. Open index.html in your browser.

---

## ☁️ Steps to Deploy on AWS EC2

1. Launch an EC2 instance.
2. Install Apache:
   sudo apt update
   sudo apt install apache2
3. Copy index.html file:
   sudo cp index.html /var/www/html/
4. Open browser and enter:
   http://your-ec2-public-ip
